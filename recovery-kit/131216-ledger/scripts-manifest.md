# 131216 ledger — scripts manifest (referenced, not copied)

Every artifact needed to rebuild the 131216 ledger already lives in this repository under
`deploy/`, `ops/`, `services/` and `console/`. This kit **references** them so there is one
source of truth; `tools/verify-kit.sh` check (7) fails if any path below stops existing.

No `.env` file is listed: the per-role env files are gitignored and are an extraction item
(`00-PRE-TEARDOWN-EXTRACTION.md` E7). Only `*.env.example` templates appear here.

**Order step** refers to the Bring-up order in `README.md`.
